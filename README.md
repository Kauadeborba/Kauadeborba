# Olá, eu sou Kauã

Sou estudante de **Engenharia de Software** e atuo como **Desenvolvedor Web**, com foco em **Frontend** e integração com **Backend**.

Atualmente trabalho na manutenção e evolução de aplicações em produção, desenvolvendo interfaces, integrações e soluções voltadas para problemas reais de negócio.

### Tecnologias e conhecimentos

* **Frontend:** TypeScript, React, Next.js, Tailwind CSS
* **Backend & APIs:** APIs REST, autenticação e autorização
* **Banco de dados:** PostgreSQL, MySQL, MongoDB
* **Automação:** n8n
* **Desenvolvimento:** manutenção de sistemas, integração entre serviços, correção de bugs e implementação de novas funcionalidades

Tenho interesse em construir aplicações bem estruturadas, entender os problemas por trás das demandas e evoluir continuamente como desenvolvedor.
